📖 使用说明

✦ 文生图

根据文字描述生成图片。提示词越具体，效果越好。

[主体] + [场景] + [风格] + [光照] + [构图] + [质量要求]

例：一座悬浮在晨雾峡谷上方的发光城市，电影级写实风格，广角构图，丰富的建筑细节，柔和金色光线，高信息密度

◈ 图生图

基于已有图片进行风格转换、场景重塑或视觉增强，尽量保持原图构图。

[修改要求] + [新风格/场景] + [添加/移除元素] + [保留元素]

例：将场景转换为雨夜赛博朋克风格，添加霓虹灯反射，保持原有构图和主体结构

⚡ 高信息密度

模型针对复杂、细节丰富的画面优化。建议明确描述视觉层级。

  • 主体（画面核心对象）
  • 背景环境（场景氛围）
  • 次要元素（丰富画面层次）
  • 风格与光照（整体调性）
  • 构图约束（视角、景别）

⚙ 注意事项

  • API Key 仅存储在浏览器本地
  • 图片生成需数秒至数十秒，请耐心等待
  • 图生图需先上传或输入图片 URL
  • 生成费用：$0.003/张
  • 建议客户端超时 60-360 秒
